# StreamGrab v1.2.0 — design overhaul

**A completely redesigned interface, same obsessive engine underneath. New design system, guided flows, and a test suite that audits the UI itself.**

---

## ✨ What changed

### New design system
- Design tokens for light/dark themes with an indigo → violet accent and an AA-contrast palette throughout.
- Clean Inter/Segoe-style typography with tabular numbers, soft shadows and subtle motion (fully respects `prefers-reduced-motion`).

### Popup, rebuilt piece by piece
- **Header**: logo, current-site pill and a live "downloads in progress" indicator.
- **Tabs**: segmented control with counters so you always know where things are.
- **Cards**: thumbnail preview with format/duration chips, 2-line clamp titles, size + quality chips, a Video/Audio switch, a custom quality dropdown (★ best), and a full-width primary button.
- **Progress you can read**: status, percentage, bytes downloaded, speed, ETA and cancel — with queued/muxing animations, a success strip ("Show") and an error strip ("Retry").
- **Notices that respect you**: clear DRM / live-stream warnings instead of silent failures; skeleton states while analysing.
- **Empty states**: guided 3-step empty state plus a blob warning; toasts (not tooltips) for "Copied!".

### History tab
- Thumbnails (or typed tiles) with status badges, **sticky day headers**, totals summary, hover actions and ellipsised metadata — dense but calm.

### Settings tab
- Grouped sections with icons, segmented controls (parallel downloads, theme, language), filename-template chips **with live preview**, and an about card.

## 🧪 Testing

- **Design gallery** (`npm run test:gallery`): renders the real popup with simulated states (long/unbroken titles, 403 errors, queue, DRM, live, 40-entry history, empty/blob states) in light/dark × EN/ES, then audits overflow, clipped text, spill-out, tap targets and WCAG AA contrast. The audit itself is self-tested with deliberately broken CSS.
- Fixed by the audit before release: low-contrast amber notices, dimmed history rows, template chips below tap-target size, a button overhanging its card, error text overlapping the Retry button.

## 📦 Files

- `streamgrab-chrome-v1.2.0.zip` — Chrome, Edge, Brave, Opera, Vivaldi (unzip → "Load unpacked").
- `streamgrab-firefox-v1.2.0.zip` — Firefox (≈140+) via `about:debugging` → Load Temporary Add-on.

## ℹ️ Notes

- Everything still runs 100% locally: no servers, no accounts, no analytics.
- Same engine as v1.1.x: HLS/DASH/blob detection, frame-accurate muxing, AES-128, Referer emulation, auto-download, size limits, 1-hour videos.
