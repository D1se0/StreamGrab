# StreamGrab v1.1.0

**Download from history, redesigned popup, and the same frame-perfect engine you already trust.**

## ✨ New

### History of downloads
- Every completed download is recorded with **title, quality, size, source page and stream URL** (up to 200 entries, oldest pruned automatically).
- **One-click re-download** from history. It re-analyses the live manifest (streams often change under the same URL), and you can **pick a different quality** than the one you originally saved — the popup's selector always wins over the recorded one.
- Per-entry actions: **open the file**, **show its folder**, **copy the URL**, and delete individually.
- **Clear-all** plus a **stats line**: number of downloads and total bytes saved.

### Popup redesign
- Two tabs: **Videos** (live detections for the current tab) and **History**.
- **Search filter** across the history (title, URL, quality).
- Light/dark theme follows your browser, cards for every stream, badges for HLS / DASH / FILE, honest per-phase progress (segments → assembly → save).
- Available in **Spanish and English**.

## 🔧 Under the hood
- Background service worker gained state-based history persistence (`storage.local`) and safer helpers; the download job pipeline now carries provenance (page title, URL, chosen option) into history entries.
- Re-downloads validate the manifest again and gracefully read old history data on upgrade — no migration step needed.

## ✅ Verified (this exact release)
- **Build**: `npm run build` clean, no warnings.
- **Unit tests**: engine suite green against real fixtures (ffprobe checks codecs, resolution, exact frame counts).
- **E2E**: 36/36 checks in real Chromium (ungoogled-chromium), including:
  - blob:/MSE page with HLS ladder → master-only listing, quality order, toolbar badge.
  - Full download → MP4 verified with **ffprobe**: H.264 + AAC, 640×360, ~12 s, **300/300 frames**, zero decode errors.
  - Hotlink-protected stream via declarativeNetRequest Referer/Origin emulation.
  - Manifests disguised as `text/plain` (fetch and XHR sniffing).
  - DASH download with merged audio+video.
  - Size limit honoured (SIZE_LIMIT).
  - **1-hour stream: 108,000 frames, 3600 s, no call-stack regressions.**
  - Auto-download after reload.
  - Full history cycle published here: recorded → stats → re-download (180p) → new MP4 verified → search filter → cards render → delete one → clear all.
- **Firefox**: same engine code, `web-ext lint` clean (0 errors / 0 warnings). No live-Firefox e2e exists in this environment.
